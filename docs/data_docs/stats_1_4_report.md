## 关键结论与 max_input_length 建议
- 所有数据集全输入 BPE 估算 **p99 最大值 = 3572**
- B0 阶段（text-only）`max_input_length` 可先设为 512；
- B1 起建议使用 1024，并允许 DataLoader/Collator 截断超长结构尾部；
- DDI 依然必须结合实体居中正文窗口，不能直接把全文级结构串完整送入模型。
