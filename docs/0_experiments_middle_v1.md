# 中期报告阶段性内容

## 一、论文的研究进展情况、阶段性成果论述

本论文围绕“基于生成式模型的生物医学关系抽取研究”展开，整体目标是在生物医学文本中引入可解释、可控制的句法结构知识，提升生成式模型对实体关系的理解与结构化生成能力。根据开题报告中的总体设想，论文计划从多视角依存结构构建、生成式模型优化以及低资源情景学习三个方面展开研究。目前研究工作主要推进至第一个研究内容，即面向生成式生物医学关系抽取的依存结构知识建模与筛选。该部分的核心问题是：什么样的依存句法知识对下游生成式关系抽取模型真正有用，以及如何将此类结构知识以生成式模型能够吸收的形式注入模型。

围绕上述目标，前期首先完成了实验方案的细化。在原开题报告“多视角依存结构去噪融合与线性化”的基础上，进一步将研究内容具体化为实体感知图粗化、语义-句法双视角表示学习、面向生成任务的信息瓶颈筛选以及可控结构注入等模块。该设计针对生物医学文本中多词实体普遍存在、依存解析噪声较多、原始依存树冗余信息较强等问题，尝试从结构压缩和生成导向优化两个角度，为 BioBART 等生成式模型提供更稳定的结构先验。

在数据准备方面，研究已完成 CDR、ChemProt 和 DDI 三类公开生物医学关系抽取数据集的获取、格式统一、依存解析、实体边界对齐与实体感知图粗化处理。原始数据被统一转换为围绕“句子、实体对、关系标签、依存结构”的 JSON 格式，并通过 SciSpaCy 生成依存树信息。针对多词实体内部依存弧可能干扰关系信号的问题，已实现实体感知图粗化算法，将多词实体折叠为超级节点，删除实体内部噪声弧，并保留实体与外部谓词或修饰成分之间的有效依存联系。

在此基础上，研究进一步对实验视图进行了调整与冻结。由于依存结构、最短依存路径和结构线性化本质上主要描述句内关系，若直接使用全文级实体对，会引入跨句证据聚合、长文本截断、跨句 SDP 不可定义等额外因素，从而干扰“依存知识是否有效”这一核心问题的判断。因此，当前主实验视图已确定为 same-sentence / local evidence 形式，并构建了 ChemProtSent 与 CDRIntra 两个句级主实验数据集。其中 ChemProtSent 保留同句中的化学物质-基因实体对，CDRIntra 保留同句中的化学物质-疾病实体对，并统一引入 NO_RELATION 负类标签。相关 DataLoader、Collator、输入构造模块均已完成验证，能够支持 text-only 与 dependency-enhanced 两种输入形式。

阶段一数据工作不仅完成了数据预处理，也解决了一系列影响后续实验可靠性的工程问题。例如，早期 tokens 与依存解析结果长度不一致的问题已通过使用 SciSpaCy token 重建实体边界得到修复；实体重叠导致图粗化异常的问题已通过安全退化策略处理；DDI 数据中负例采样污染验证集与测试集的问题已修正为仅训练集采样；长样本截断后结构信息与正文窗口不一致的问题也已通过结构退化逻辑处理。经过抽样验证，当前数据层已经具备支撑后续 baseline 与核心模型实验的条件。

在 baseline 验证方面，阶段二完成了生成式关系抽取基础框架的搭建与系统对比实验。该阶段统一使用 BioBART 作为生成式 backbone，并设置五组基线：B0 为 text-only；B1-raw 为原始依存树线性化拼接；B2-raw 为原始依存图上的最短依存路径拼接；B1-coarse 为粗化依存树线性化拼接；B2-coarse 为粗化图上的最短路径拼接。实验在 ChemProtSent、CDRIntra 和 DDI 三个数据集上进行，并补齐了 42、123、456 三个随机种子的结果。

阶段二结果表明，结构注入在不同数据集上表现出差异性。在 ChemProtSent 上，B2-coarse 取得最高 mapped exact，说明粗化后的最短依存路径能够在该数据集上提供有效的结构辅助；在 CDRIntra 上，B2-coarse 也略优于 B2-raw，表明最短路径形式整体优于整树拼接，实体折叠具有一定积极趋势；而在 DDI 上，当前设置下 text-only baseline 最优，说明并非所有数据集都能从直接结构拼接中受益，也提示后续需要更精细的结构筛选机制，而不是简单地将依存树完整加入模型输入。总体而言，阶段二初步回答了“依存信息是否值得继续研究”的问题，并为后续双视角建模与信息瓶颈方法提供了实验依据。

在核心模型实现方面，阶段三已完成图增强建模链路。研究新增了 GraphBuilder、BioREGraphDataset 和 BioREGraphCollator，用于将阶段一得到的粗化依存图转换为邻接矩阵、依存类型矩阵、节点 mask、实体节点索引等图张量。同时，构建了两个互补的表示视角：一是基于 PubMedBERT 的语义视角，用于提取句子级语义表示和图节点初始表示；二是基于 Attentive GCN 的句法视角，用于在粗化依存图上传递结构信息，并输出依存边的重要性初始分数。该设计使得模型不再仅依赖线性化结构文本，而是能够直接对依存图进行表示学习。

为验证语义视角与句法视角的作用，阶段三前半部分完成了 B3、B4、B5 三组图增强基线实验。其中 B3 为 syntax-only，使用依存图编码后的句法表示作为 BioBART 的额外注入向量；B4 为 semantics-only，使用 PubMedBERT 的句子语义表示作为额外注入向量；B5 为 dual-view concat，将语义视角与句法视角直接拼接后注入生成器。在 ChemProtSent 上，B4 取得当前中间基线最优结果，mapped exact 达到 0.901083；在 CDRIntra 上，B5 取得最优结果，mapped exact 达到 0.775451。该结果说明，图增强方向整体有效，但不同数据集对语义信息与句法结构的依赖程度并不一致。ChemProtSent 更依赖局部语义与实体上下文，CDRIntra 则表现出更明显的语义-句法互补特征。

值得注意的是，B5 的简单双视角拼接并不在所有数据集上都优于单视角方法。该现象表明，直接拼接可能引入冗余甚至噪声，当句法结构对部分样本贡献有限时，模型缺少主动筛选有效结构的机制。因此，研究进一步实现了面向生成任务的信息瓶颈模型 EA-GMIB/Ours，希望通过边级保留概率学习，使模型自动选择对生成式关系抽取最有帮助的依存弧。

阶段三后半部分已完成 Ours-v1 的实现与诊断。Ours-v1 复用语义视角、句法视角和 GM-IB 模块，通过 Binary Concrete 采样学习每条依存边的保留概率，并利用压缩损失控制结构保留比例。实验结果显示，Ours-v1 在 ChemProtSent 上与 B5 非常接近，在 CDRIntra 上略高于 B5，形式上达到阶段性性能目标。但进一步机制分析发现，两个数据集在 best epoch 上的 eval compression ratio 均为 0，说明评估阶段 hard selection 没有选中任何边，模型触发了 fallback pooling。随后进行的 threshold sweep 进一步表明，ChemProtSent 的边概率几乎塌缩为常数，CDRIntra 虽然边概率存在一定分布，但预测结果对阈值变化几乎不敏感。这说明 Ours-v1 的结构选择机制对最终生成决策影响较弱，性能接近或小幅提升并不能证明模型已经真正学到了可解释的关键依存子图。

针对上述问题，当前研究正在推进 Ours-v2 模块。Ours-v2 的主要改进包括 selected-message readout 和 target-ratio compression。前者使边选择变量不再只是影响节点池化权重，而是直接决定哪些节点信息可以沿选中依存边进行消息传递，从而增强结构选择对 BioBART 注入向量的影响；后者将压缩目标由单纯 L1 稀疏约束调整为目标保留比例约束，使平均边保留概率维持在合理范围，避免概率整体塌缩为全零或全一。目前 Ours-v2 已通过本地 smoke 与 full-config override 验证，forward/backward、温度退火、结构选择统计、target-ratio loss 记录等链路均可正常运行，且 prob compression ratio 能够接近目标比例。这表明当前研究已经从“构建结构增强模型”推进到“诊断并修复结构选择机制”的阶段。

综上，论文目前已完成研究内容一的主要数据基础、基线系统、图增强模块和 GM-IB 原型验证。阶段性成果主要体现在四个方面：其一，构建了适用于生成式 BioRE 结构实验的句级数据视图与依存图数据基础；其二，完成了结构注入 baseline 的系统验证，初步证明粗化 SDP 在主要句级数据集上具有有效性；其三，完成了语义视角、句法视角与双视角图增强模型的实现，验证了图增强方向的可行性；其四，通过 Ours-v1 的失败诊断与 Ours-v2 的修复设计，进一步明确了生成式模型中结构选择机制必须同时满足性能有效性与机制可解释性。当前研究进展与开题报告中的总体目标保持一致，并为后续持续预训练、结构化数据生成和低资源情景学习研究奠定了基础。

## 二、后续工作的设想、论文的主要创新点、可能遇到的困难和问题及解决方案

后续工作将首先围绕 Ours-v2 展开。当前 Ours-v2 已通过本地链路验证，但仍需在 ChemProtSent 与 CDRIntra 上完成正式 full run，并在性能指标和机制指标两方面进行综合判断。性能上，将重点比较 Ours-v2 与 B4、B5 等中间基线的 mapped exact；机制上，将重点观察 eval prob compression ratio、hard selection compression ratio、target-ratio loss、平均保留边数等指标，确认模型是否真正形成稳定的边级结构选择能力。在 Ours-v2 取得稳定结果后，将进一步补充多随机种子实验、正式消融实验、参数敏感性实验、按句长和实体词数分桶的鲁棒性分析，以及典型样例的依存图可视化与边筛选分析。

本论文当前阶段的主要创新点可概括为三个方面。第一，问题层面上，将依存句法知识筛选问题从传统判别式关系分类场景推进到生成式 BioRE 场景，关注“哪些结构知识能够帮助序列生成”。第二，方法层面上，提出实体感知图粗化策略，针对生物医学多词实体内部噪声弧进行结构压缩，并结合语义视角与句法视角构建多视角表示。第三，机制层面上，设计面向生成任务的信息瓶颈模块，尝试以生成损失和结构压缩约束共同驱动依存弧筛选，使模型不仅获得性能增益，也能输出可解释的结构选择结果。

后续可能遇到的主要困难包括：其一，BioBART 与 PubMedBERT 语义能力较强，模型可能绕开图结构选择，导致结构模块对最终预测影响不足；其二，GM-IB 中边选择概率容易出现塌缩，可能产生全选或全不选现象；其三，不同数据集对结构信息的敏感度不同，可能导致同一结构方法在 ChemProtSent、CDRIntra 与 DDI 上表现不一致；其四，完整模型计算开销较大，多随机种子和消融实验需要较多 GPU 时间。

针对上述问题，研究将采取分层解决策略。在模型机制上，继续推进 Ours-v2 的 selected-message readout，使边选择直接参与图消息传递；通过 target-ratio compression、阈值分析和 beta/目标比例调参，维持稳定的结构保留比例。在实验设计上，采用“性能指标+机制指标”双重标准，避免只凭最终准确率判断结构模块是否有效；同时通过消融实验和分桶分析区分实体粗化、句法视角、语义视角和信息瓶颈各自的贡献。在工程实施上，优先完成两个主力句级数据集的正式实验，再根据时间和资源补充 DDI 或附加分析，确保论文中期以后能够形成稳定、可信且可解释的实验结论。
