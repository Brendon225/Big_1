# 中期报告阶段性内容

## 一、论文的研究进展情况、阶段性成果论述

本论文围绕“基于生成式模型的生物医学关系抽取研究”展开，整体目标是在生物医学文本中引入可解释、可控制的结构化知识，提升生成式模型对实体关系的理解能力与关系标签生成能力。与传统判别式关系分类方法不同，生成式关系抽取需要模型在阅读句子和实体对的基础上，直接生成合法的关系标签，因此模型不仅要理解生物医学实体本身，还需要判断实体之间是否存在明确的局部证据。基于这一特点，当前研究重点围绕“如何将实体级、句法级和语义级信息组织成生成式模型能够有效利用的输入和表示”展开。

根据开题报告中的总体设想，论文原计划从依存结构建模、生成式关系抽取模型优化以及低资源情景学习等方面推进。进入实际实验阶段后，研究首先聚焦于第一个核心问题，即在生物医学关系抽取任务中，哪些结构信息能够真正帮助生成式模型。该问题看似是模型设计问题，但其前提首先是数据视图是否合理。如果数据仍停留在全文级实体对层面，依存路径、句法图和局部关系触发词都会受到跨句证据、长文本截断和实体距离过远等因素干扰，导致后续模型实验难以判断结构信息本身是否有效。因此，前期工作首先对数据准备、主实验视图和依存图构建进行了系统梳理。

在数据准备方面，研究已完成 CDR、ChemProt 和 DDI 三类公开生物医学关系抽取数据集的获取、格式统一、依存解析、实体边界对齐与实体感知图粗化处理。原始数据被统一转换为围绕“句子、实体对、关系标签、依存结构”的 JSON 格式，并通过 SciSpaCy 生成依存树信息。针对生物医学文本中多词实体普遍存在的问题，研究实现了实体感知图粗化算法，将多词实体折叠为一个实体节点，删除实体内部依存噪声，并保留实体与外部谓词或修饰成分之间的有效依存联系。例如，在句子 “Epidermal growth factor receptor inhibitors currently under investigation include the small molecules gefitinib” 中，`Epidermal growth factor receptor` 是一个多词生物医学实体。如果直接保留每个词的依存节点，模型会同时看到 `Epidermal`、`growth`、`factor`、`receptor` 等实体内部结构，容易把实体内部修饰关系误当作关系判断证据；而粗化后，该实体被视为一个整体节点，句法图更集中于实体与 `inhibitors`、`include`、`gefitinib` 等外部关系线索之间的连接。

【图示建议 1：在此处插入 ChemProt 典型例句的原始依存图与粗化后依存图对比。图中建议突出 `Epidermal growth factor receptor` 被折叠为一个实体节点，以及折叠前后依存路径由“实体内部碎片化结构”转向“实体间外部路径”的变化。】

在实验视图方面，研究已将主实验数据固定为句级 local evidence 视图，重点使用 ChemProtSent 与 CDRIntra 两个主数据集。ChemProtSent 保留同一句中的化学物质-基因实体对，CDRIntra 保留同一句中的化学物质-疾病实体对，并统一引入 `NO_RELATION` 负类标签。这样处理的原因在于，依存结构和最短依存路径本质上主要描述句内关系。如果直接使用全文级实体对，模型可能依赖跨句共现或上下文截断后的残缺证据，进而掩盖依存结构是否有效这一核心问题。通过句级视图，当前实验能够更直接地回答：当两个实体出现在同一句中时，句法图、实体折叠和语义增强是否能够帮助生成式模型更准确地生成关系标签。

阶段一数据工作不仅完成了常规预处理，也解决了一系列会影响后续实验可信度的工程问题。早期 tokens 与依存解析结果长度不一致的问题，已通过使用 SciSpaCy token 重建实体边界得到修复；实体重叠导致图粗化异常的问题，已通过安全退化策略处理；DDI 数据中负例采样污染验证集与测试集的问题，已修正为仅在训练集采样；长样本截断后结构信息与正文窗口不一致的问题，也已通过结构退化逻辑处理。上述修复使得后续实验能够建立在稳定、可复现的数据基础上，而不是把数据层噪声误解释为模型性能差异。

【表格建议 1：可在此处加入“数据准备阶段产物表”，列出 raw、processed、parsed、coarsened、experiment views 五个阶段，以及每一阶段的主要字段，如 tokens、dep_heads、coarse_tokens、coarse_heads、relation label、entity spans 等。】

在基线实验方面，阶段二完成了生成式关系抽取基础框架的搭建。该阶段统一使用 BioBART 作为生成式 backbone，并设置了 text-only、原始依存树线性化、原始最短依存路径、粗化依存树线性化和粗化最短依存路径等多组 baseline。阶段二的主要意义不在于得到最终模型，而在于确认直接结构注入是否具有继续研究的价值。实验结果表明，结构注入在不同数据集上表现出明显差异：在 ChemProtSent 和 CDRIntra 上，粗化后的最短依存路径具有一定积极趋势；而在 DDI 上，纯文本 baseline 仍然较强，说明并非所有数据集都能从简单结构拼接中受益。该结果提示后续模型不能简单地把整棵依存树或线性化路径拼接给生成器，而需要更细致地建模语义视图、句法视图及其融合方式。

在此基础上，阶段三完成了图增强建模链路。研究新增了 GraphBuilder、BioREGraphDataset 和 BioREGraphCollator，用于将阶段一得到的粗化依存图转换为邻接矩阵、依存类型矩阵、节点 mask、实体节点索引等图张量。同时，模型设计了两个互补的表示视角：一是基于 PubMedBERT 的语义视图，用于提取句子级语义表示和图节点初始表示；二是基于 GCN 的句法视图，用于在粗化依存图上传递结构信息。语义视图更擅长理解生物医学实体和关系触发词的领域含义，句法视图则更关注实体之间通过哪些依存路径连接。二者并不是替代关系，而是从不同角度描述同一实体对。

为验证各模块的作用，阶段三和阶段四进一步完成了多组对比实验。当前正式汇报中重点采用关系抽取论文中更常用的 Precision、Recall、Micro-F1 和 Macro-F1，并在计算时排除 `NO_RELATION` 类，以避免负类样本过多导致指标虚高。根据 test split 三随机种子结果，最终主模型 B7 gated dual-view 在 ChemProtSent 上相比纯文本 BioBART baseline 获得明显提升，在 CDRIntra 上也保持稳定增益。具体结果如下表所示。

| Dataset | Model | Precision | Recall | Micro-F1 | Macro-F1 |
|---|---|---:|---:|---:|---:|
| ChemProtSent | B0 text-only | 0.7052 | 0.6240 | 0.6461 | 0.6065 |
| ChemProtSent | B7 gated dual-view | 0.7685 | 0.6857 | 0.7246 | 0.7070 |
| CDRIntra | B0 text-only | 0.5880 | 0.5859 | 0.5457 | 0.5457 |
| CDRIntra | B7 gated dual-view | 0.6760 | 0.6738 | 0.6737 | 0.6737 |

【图示建议 2：在此处插入 B0 与 B7 的 Micro-F1 柱状图。建议分别展示 ChemProtSent 和 CDRIntra 两组数据，使读者能够直观看到最终模型相对纯文本生成式 baseline 的提升幅度。】

从模型结构看，B7 的核心在于将 PubMedBERT 语义视图和 GCN 句法视图进行门控融合，再将融合后的表示注入 BioBART。与简单拼接不同，门控融合并不是把两路向量机械连接，而是学习在不同样本中语义信息和句法信息的相对贡献。为了验证该机制是否有效，研究进一步比较了 B5 dual-view concat 与 B7 gated dual-view。两者都使用语义视图和句法视图，区别主要在融合方式：B5 直接拼接两路表示，B7 使用门控机制进行动态加权。结果显示，在 ChemProtSent 上，B7 的 Micro-F1 为 0.7246，高于 B5 的 0.7133；在 CDRIntra 上，B7 与 B5 基本持平，且保持较高 Recall。该结果说明，门控融合在主数据集上能够带来进一步提升，同时在不同数据集上表现出一定的适应性。

| Dataset | B0 text-only Micro-F1 | B5 concat Micro-F1 | B7 gated Micro-F1 |
|---|---:|---:|---:|
| ChemProtSent | 0.6461 | 0.7133 | 0.7246 |
| CDRIntra | 0.5457 | 0.6764 | 0.6737 |

除了双视角融合，研究还单独考察了语义视图的作用。B4 semantics-only 只注入 PubMedBERT 领域语义表示，不使用 GCN 句法图，也不使用门控融合。实验结果显示，B4 在两个主数据集上均显著优于 B0：ChemProtSent 的 Micro-F1 从 0.6461 提升到 0.7097，CDRIntra 的 Micro-F1 从 0.5457 提升到 0.6818。这说明领域语义不是附加装饰，而是生成式生物医学关系抽取的重要基础。PubMedBERT 能够补足 BioBART 对生物医学实体、缩写、药物名称和关系触发词的领域理解，后续双视角框架正是在这一语义基础上进一步融合句法结构。

| Dataset | B0 text-only Micro-F1 | B4 semantics-only Micro-F1 | 提升 |
|---|---:|---:|---:|
| ChemProtSent | 0.6461 | 0.7097 | +6.36 pts |
| CDRIntra | 0.5457 | 0.6818 | +13.61 pts |

实体折叠的作用也通过 B7 raw graph 与 B7 coarse graph 消融进行了初步验证。两组模型均使用 PubMedBERT 语义视图、GCN 句法视图、门控融合和 BioBART，区别只在 syntax graph 使用原始依存图还是实体折叠后的粗化图。该消融表主要用于观察 raw/coarse 在同一对照设置下的相对差异，正式主结果仍以多随机种子均值为准。在 ChemProtSent 上，B7 coarse graph 的 Micro-F1 为 0.7368，高于 B7 raw graph 的 0.7145，Recall 也从 0.6662 提升到 0.6973，说明实体折叠能够在多类别 ChemProt 关系识别中减少多词实体内部噪声，使 GCN 更集中于实体之间的外部依存路径。在 CDRIntra 上，coarse graph 的 Precision 高于 raw graph，但 Recall 下降，反映出实体折叠会改变句法图的信息密度，并在不同数据集上形成不同的 precision-recall 取舍。该结果说明，实体折叠并不是无条件提升所有场景，而是通过压缩实体内部结构影响模型对关系证据的利用方式。

| Dataset | Model | Precision | Recall | Micro-F1 | Macro-F1 |
|---|---|---:|---:|---:|---:|
| ChemProtSent | B7 raw graph | 0.7703 | 0.6662 | 0.7145 | 0.6909 |
| ChemProtSent | B7 coarse graph | 0.7811 | 0.6973 | 0.7368 | 0.7206 |
| CDRIntra | B7 raw graph | 0.6705 | 0.7067 | 0.6881 | 0.6881 |
| CDRIntra | B7 coarse graph | 0.6892 | 0.6097 | 0.6470 | 0.6470 |

【图示建议 3：在此处插入“raw graph 与 coarse graph 消融对比图”。可以用两组小柱状图分别展示 ChemProtSent 的 Micro-F1 提升和 CDRIntra 的 Precision-Recall trade-off，避免只强调单一指标。】

值得说明的是，研究过程中也尝试过基于 GM-IB 的离散边选择机制，希望模型能够自动筛选关键依存弧并形成可解释的结构子图。但实验诊断表明，hard selection 在当前生成式框架下存在不稳定问题，容易出现边选择概率塌缩、阈值变化对预测影响不明显等现象。因此，当前论文主线不再强调离散边压缩作为最终方法，而是将其作为探索性诊断保留。相比之下，B7 采用连续门控融合，结构更简单、训练更稳定，也更适合作为当前阶段写入论文主线的模型。

综上，论文目前已完成数据准备、基线验证、图增强建模、双视角融合和初步消融分析等核心工作。阶段性成果主要体现在四个方面：其一，构建了适用于生成式 BioRE 结构实验的句级数据视图与实体感知粗化依存图；其二，完成了 BioBART 生成式 baseline 与结构增强 baseline 的系统验证；其三，实现了 PubMedBERT 语义视图、GCN 句法视图和门控双视角融合模型，并在两个主数据集上取得相对纯文本 baseline 的稳定提升；其四，通过 semantics-only、concat-vs-gated 和 raw-vs-coarse 等消融实验，初步说明了语义视图、门控融合和实体折叠在不同层面的作用。当前研究进展与开题报告中的总体目标保持一致，并已形成较为清晰的论文实验主线。

## 二、后续工作的设想、论文的主要创新点、可能遇到的困难和问题及解决方案

后续工作将围绕“补齐论文级证据链”展开，而不是继续盲目增加模型复杂度。首先，需要继续完善单视角与模块消融实验。当前 B4 semantics-only 已证明 PubMedBERT 领域语义视图具有明显贡献，B5 与 B7 的对比初步说明门控融合相比简单拼接更适合作为最终机制。后续将补齐 B3 syntax-only 的完整实验结果，使语义视图、句法视图、双视角拼接和门控融合之间形成更完整的对照关系。同时，将继续整理 raw graph 与 coarse graph 的消融结果，分析实体折叠在不同数据集和不同关系类型上的作用差异。

其次，需要从总体指标进一步推进到细粒度分析。当前主表已经报告 Precision、Recall、Micro-F1 和 Macro-F1，但这些指标只能说明模型整体性能，不能解释模型在哪些关系类别上更强、在哪些类别上更容易失败。后续将补充 per-class F1、confusion matrix 和典型案例分析。对于 ChemProtSent，将重点观察 CPR:3、CPR:4、CPR:5、CPR:6、CPR:9 等关系类别之间的差异；对于 CDRIntra，将重点分析 CID 正类的召回不足、负类误报以及 raw/coarse 图在召回和精度上的取舍。通过这些分析，可以将实验结论从“模型分数更高”推进到“模型在何种关系、何种句法结构和何种实体复杂度下更有效”。

【表格建议 2：在此处加入 per-class F1 结果表。ChemProtSent 可列出 CPR:3、CPR:4、CPR:5、CPR:6、CPR:9 的 support、Precision、Recall、F1；CDRIntra 可列出 CID 的 Precision、Recall、F1，并补充主要错误类型。】

再次，需要开展鲁棒性和分桶分析。生物医学关系抽取中的错误往往与句子长度、实体距离、实体词数、依存路径长度和关系类别不平衡有关。后续将按句长、实体间 token 距离、多词实体长度、最短依存路径长度等维度进行分桶，观察 B7 相比 B0、B4、B5 在不同样本子集上的变化。如果 B7 在长距离实体、长依存路径或多词实体样本上更有优势，则能够进一步支撑“句法图与实体折叠有助于处理复杂结构关系”的论文叙事；如果某些分桶中 B7 表现不如 B4 或 B5，也可以作为模型局限进行诚实分析。

【图示建议 4：在此处插入后续工作路线图，可分为三条线：模块消融、细粒度错误分析、鲁棒性分桶分析。每条线下列出对应交付物，如 B3 syntax-only、per-class F1、confusion matrix、case study、bucket analysis。】

本论文当前阶段的主要创新点可概括为三个方面。第一，数据与问题建模层面，论文没有直接沿用全文级实体对，而是构建了面向依存结构实验的句级 local evidence 视图，使生成式关系抽取中的句法知识验证更加聚焦。第二，结构建模层面，论文引入实体感知图粗化策略，将多词生物医学实体折叠为紧凑节点，缓解实体内部依存噪声对关系路径建模的干扰。第三，模型层面，论文构建了语义视图与句法视图互补的双视角生成式关系抽取框架，并通过门控融合机制学习两类证据的动态贡献，使 BioBART 不再仅依赖原始文本，而能够吸收领域语义和依存图结构信息。

后续可能遇到的主要困难包括：其一，BioBART 与 PubMedBERT 本身语义能力较强，句法结构模块的边际贡献可能在部分数据集上不明显；其二，不同数据集对结构信息的敏感度不同，同一模块可能在 ChemProtSent 上有效，但在 CDRIntra 上体现为 precision-recall trade-off；其三，关系类别不平衡会影响 Macro-F1 和少数类表现，单看总体 Micro-F1 容易掩盖细粒度错误；其四，多随机种子、消融实验和分桶分析计算开销较大，需要合理安排实验优先级。

针对上述问题，研究将采取分层解决策略。在实验设计上，优先补齐 B3 syntax-only、B4 semantics-only、B5 concat 和 B7 gated fusion 之间的对照关系，用模块消融明确语义、句法和融合机制各自的贡献。在结果分析上，采用总体指标与细粒度指标结合的方式，除 Micro-F1 和 Macro-F1 外，进一步报告 per-class F1、confusion matrix 和典型样本分析，避免只凭单一分数判断模型优劣。在工程实施上，优先完成 ChemProtSent 与 CDRIntra 两个主实验数据集的完整归档，再根据时间补充 DDI 或更多附加分析。在论文写作上，将对 GM-IB 等不稳定探索保持谨慎表述，把重点放在实体感知粗化图、语义-句法双视角表示以及门控融合这条更稳定、可复现的主线上，确保最终论文形成清晰可信的实验闭环。
