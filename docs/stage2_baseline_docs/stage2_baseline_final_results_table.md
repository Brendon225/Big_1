## 1. 文档定位

本文档给出阶段二全部三个数据集的最终汇总结果表，统一采用：

- 5 组 baseline
- 3 个随机种子（`42/123/456`）
- 同一训练设置（`epoch=1`, `target_mode=relation_only`, `prediction_mode=label_rerank`）

说明：

- 本表是阶段二最终结果总表
- 详细过程说明见阶段二完整实验报告

## 2. 指标说明

当前阶段二统一汇总以下指标：

- `train_loss_mean ± std`
- `eval_loss_mean ± std`
- `mapped_exact_mean ± std`
- `invalid_rate_mean`

说明：

- `mapped_exact` 用于阶段二结构注入方案的统一比较
- `invalid_rate` 用于衡量输出是否合法
- 当前三数据集所有组别的 `invalid_rate_mean = 0`
