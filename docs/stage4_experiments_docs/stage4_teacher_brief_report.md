# Stage4 阶段性实验结果汇报简报

日期：2026-06-03

## 1. 当前阶段目标

本阶段的目标是将前面已经训练完成的模型统一转化为论文标准的 test split F1 结果，用于判断：

1. 纯文本生成式模型是否已经足够强；
2. 直接注入依存结构是否稳定有效；
3. 实体感知图粗化是否能改善结构注入；
4. 显式语义/句法双视角建模是否优于简单结构线性化 baseline。

本轮评估统一采用 `label_rerank`，所有 Precision / Recall / Micro-F1 / Macro-F1 均排除 `NO_RELATION`，同时保留 `mapped_exact` 和 `invalid_rate` 作为生成式输出质量参考。

## 2. 主要实验设置

本轮主要评估两个主实验数据集：

| 数据集 | 说明 |
|---|---|
| ChemProtSent | 化学物质-蛋白质句级关系抽取 |
| CDRIntra | 化学物质-疾病句内关系抽取 |

评估模型包括三组：

| 类别 | 模型 | 目的 |
|---|---|---|
| 纯文本 baseline | B0 text-only | 判断 BioBART 纯文本能力 |
| 依存线性化 baseline | B1 raw/coarse tree, B2 raw/coarse SDP | 判断结构注入、实体粗化和结构形式的影响 |
| Stage3 模型 | B4 semantics-only, B5 dual-view concat, B7 gated dual-view | 判断显式语义/句法建模收益 |

所有结果均为 seed `42 / 123 / 456` 三次运行的均值和标准差。

## 5. 当前主要观察

### 5.1 纯文本 BioBART 已经是较强 baseline

B0 text-only 在两个数据集上都有较强表现，说明任务本身不能只靠简单增加模型复杂度解释。后续模型提升需要和 B0 对比，才能证明结构或多视角信息确实有额外贡献。

与 B0 相比，当前最优 Stage3 模型提升如下：

| 数据集 | B0 Micro-F1 | 最优 Stage3 Micro-F1 | 提升 |
|---|---:|---:|---:|
| CDRIntra | 0.5457 | 0.6818 | +0.1361 |
| ChemProtSent | 0.6461 | 0.7246 | +0.0785 |

### 5.2 直接依存线性化不稳定

B1 tree 和 B2 SDP 的结果显示，直接把依存结构线性化拼接到生成模型输入中并不总是有效。尤其在 CDRIntra 上，B1/B2 均低于 B0，说明原始或完整结构中存在噪声，简单拼接可能干扰生成模型。

这说明本研究的问题设置是合理的：结构信息不是“直接加进去就有用”，而是需要更合适的筛选、建模或融合方式。

### 5.3 实体粗化对 SDP 注入有明显帮助

实体粗化在 B2 SDP 路径上有较清楚的收益：

| 数据集 | B2 raw SDP | B2 coarse SDP | 提升 |
|---|---:|---:|---:|
| CDRIntra | 0.4886 | 0.5111 | +0.0225 |
| ChemProtSent | 0.5904 | 0.6476 | +0.0571 |

因此，目前可以较稳妥地认为：实体感知图粗化能够改善 SDP 线性化结构注入，尤其在 ChemProtSent 上效果更明显。

不过，B1 tree 上 raw/coarse 的对比并不稳定，因此不能泛泛地说“实体粗化总是提升所有结构形式”。更准确的结论是：实体粗化对路径型结构注入更有效。

### 5.4 显式语义/句法建模显著优于线性化 baseline

与最强线性化 baseline B2-coarse 相比，Stage3 模型提升明显：

| 数据集 | B2-coarse Micro-F1 | 最优 Stage3 Micro-F1 | 提升 |
|---|---:|---:|---:|
| CDRIntra | 0.5111 | 0.6818 | +0.1707 |
| ChemProtSent | 0.6476 | 0.7246 | +0.0771 |

这说明最终收益并不是来自简单拼接依存序列，而是来自显式语义视角、句法视角以及融合模块的表示学习。

### 5.5 不同数据集偏好不同

在 ChemProtSent 上，B7 gated dual-view 最优，说明门控双视角融合能够有效吸收语义和句法信息。

在 CDRIntra 上，B4 semantics-only 的 test F1 最高，B5 和 B7 接近但略低。这说明 CDRIntra 在当前设置下可能更依赖稳健的生物医学语义表示，而不一定总是从更复杂的融合模块中获益。

## 6. 汇报时建议采用的表述

建议对当前结果做如下表述：

> 实验表明，纯文本 BioBART 已经是较强基线，简单依存线性化并不稳定，甚至在部分数据集上低于 text-only baseline。实体感知图粗化能够改善 SDP 路径注入，说明多词实体内部依存噪声确实会影响结构注入质量。进一步地，显式语义/句法表示学习显著优于所有线性化 baseline，说明结构信息需要经过模型化表示与融合，而不是简单拼接到输入中。

## 7. 下一阶段计划

目前我们已经能够证明：

1. B0 text-only 很强，但 Stage3 模型仍能明显超过它；
2. 直接依存线性化不稳定；
3. 实体粗化对 SDP 线性化有帮助；
4. Stage3 显式语义/句法建模相对线性化 baseline 有明显提升。

下一阶段计划如下：

### 7.1 补充 B7 raw graph 消融

当前 B7 使用的是 coarse dependency graph，因此实体粗化已经包含在最终模型中。若要更严格验证实体粗化对最终模型的贡献，需要补充：

```text
B7 raw graph
B7 coarse graph
```

两者保持语义视角、语法视角和门控融合结构一致，只改变 syntax view 使用 raw graph 还是 coarse graph。该实验可以作为实体粗化在最终模型层面的最强证据。

### 7.2 补充错误分析

后续可进一步分析：

1. ChemProtSent 中 B7 相比 B4/B5 主要提升哪些关系类型；
2. CDRIntra 中为什么 B4 semantics-only 最强；
3. 哪些样本是 Stage2 线性化模型预测错误、Stage3 模型预测正确；
4. 哪些错误来自 positive 被预测为 `NO_RELATION`，哪些来自关系类别混淆。

### 7.3 整理论文实验叙事

后续论文叙事建议围绕以下逻辑展开：

1. 简单依存线性化不稳定；
2. 实体感知图粗化缓解路径结构噪声；
3. 显式语义/句法建模比线性化结构注入更有效；
4. 门控融合在 ChemProtSent 上表现最好，但不同数据集存在不同偏好；
5. 因此，生成式 BioRE 中的结构知识应通过表示学习和融合机制注入，而不是直接文本拼接。
